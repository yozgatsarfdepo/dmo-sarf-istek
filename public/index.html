⚙️ Firebase Kurulumu Gerekli

Uygulama Firebase'e bağlanmadı. public/js/firebase-config.js dosyasını açıp Firebase web uygulama ayarlarınızı girin.

Firebase Konsolu → Proje Ayarları → Genel → Uygulamalar → Web uygulaması → SDK kurulumu → Yapılandırma.

export const firebaseConfig = {
  apiKey: "...",
  authDomain: "proje-id.firebaseapp.com",
  projectId: "proje-id",
  storageBucket: "proje-id.firebasestorage.app",
  messagingSenderId: "...",
  appId: "..."
};

Adım adım kurulum için proje kökündeki README.md dosyasına bakın.

🔐 Yönetici Girişi

Firebase Authentication (E-posta / Şifre) hesabınızla giriş yapın.

Hesap yoksa Firebase Konsolu → Authentication → Kullanıcılar bölümünden oluşturun ve firestore.rules içindeki e-posta listesine ekleyin.
